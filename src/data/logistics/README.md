# Logistics (Sequential, Satisficing)

## Domain Description

Classic IPC logistics domain.
Packages have to be transported between locations using trucks (that drive inside a city) and airplanes (that fly between airports of different cities).
Objects are typed (`package`, `vehicle`, `truck`, `airplane`, `city`, `airport`, `location`), and actions cover loading and unloading both vehicle classes, intra-city trucking (`drive-truck`) and inter-city flight (`fly-airplane`).
Each instance specifies an initial placement of packages and vehicles plus goal locations for some of the packages.

## Authors

Henry Kautz (1998 original PDDL formulation).
